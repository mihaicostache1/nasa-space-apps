# Lunar portrait

`moon-portrait.jpg` is the full-Moon still (`phase_full.1571_print.jpg`) linked from [Moon Phase and Libration, 2025 South Up](https://svs.gsfc.nasa.gov/5416/), NASA's Scientific Visualization Studio. Asset URL: https://svs.gsfc.nasa.gov/vis/a000000/a005000/a005049/phase_full.1571_print.jpg.

Credit: NASA's Scientific Visualization Studio. Visualizer: Ernie Wright; scientist: Noah Petro; producer: James Tralie. The source uses LRO LOLA/LROC data. The application applies decorative CSS shading and labels it illustrative. This artwork is separate from selected-date calculations and is not a terrain map or a selected-site view.
